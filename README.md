# Time Glitch — Italian Level 3 demo

Split-screen chat (**ORA** / **ALLORA**). Students pick **Presente**, **Imperfetto**, or **Passato prossimo** to fix each tense glitch.

**Live:** https://appuccinohub.github.io/time-glitch-demo/

## Pedagogy
- 6 rounds, one teen chat thread (weekend plans + Saturday flashback)
- Soft IEP feedback on misses (no red-X shame)
- Help levels on start only: More help / Just right / Challenge me
- No modal / bottom-sheet overlays (Safari-safe)

## Local
Open `index.html` or serve the folder statically.
